## Context

Cosmify starts with a very concrete problem: customising Minecraft Bedrock packs can quickly become fragile, opaque and painful to maintain. Between manifests, skin definitions, geometries, backups and files to restore, a small change can turn into a hunt for the broken file.

The goal was not to build a pretty file browser, but a **real desktop product** that makes the workflow understandable and reversible.

## The product

Cosmify imports a host pack, extracts useful information, manages skins and their resources, and restores configurations safely through automatic backups.

The central design principle is straightforward: **a risky action should remain understandable, traceable and recoverable**.

### Core features

- pack import and analysis;
- manifest and configuration parsing;
- skin and geometry management;
- backup creation and restoration;
- activity log;
- automated tests and release workflow.

## Engineering

The interface is built with React and TypeScript. Tauri provides the desktop/native layer, with Rust underneath.

That separation keeps the UI in a modern web ecosystem while providing clean access to the local filesystem.

## An end-to-end desktop product

Cosmify combines interface design, local file manipulation, data parsing, backups, restoration, activity tracking, tests and a release workflow. It therefore goes well beyond a conventional web interface wrapped in a desktop window.
